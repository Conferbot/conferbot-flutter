# Changelog

## [1.0.0] - 2024-11-25

### Added
- Initial release of Conferbot Flutter SDK
- Complete headless SDK with Provider state management
- 9 production-ready UI widgets
- Theme system with light and dark modes
- Real-time messaging via Socket.IO
- Live agent handover support
- Typing indicators
- Connection status management
- Example Flutter app with 3 usage patterns
- Full documentation

- Drop-in ChatWidget for instant integration
- Headless SDK for custom UI development
- Mix & match capability with pre-built widgets
- Offline message queueing
- Push notification support
- Full type safety with null safety
- Cross-platform (iOS & Android)
- Data structures matching embed-server schema
